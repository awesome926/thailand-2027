# Таиланд, июнь 2027

Семейный план поездки в Бангкок и на Пхукет: бюджет, маршрут по дням, еда, тайские фразы, чек-лист.

Сайт: https://awesome926.github.io/thailand-2027/

## Что где лежит

- `index.html` — разметка страницы
- `css/style.css` — оформление и анимации
- `js/app.js` — данные (маршрут, блюда, фразы, чек-лист) и вся логика
- `img/` — фотографии и иконки
- `sw.js`, `manifest.webmanifest` — офлайн-режим и установка на телефон

Сборка не нужна: это обычные статические файлы. Чтобы посмотреть локально:

```bash
python -m http.server 8765
```

и открыть http://localhost:8765

После правок в `css/`, `js/` или списке фото поменяй `VERSION` в `sw.js`, чтобы у всех обновился офлайн-кэш.

Фото: Wikimedia Commons, свободные лицензии. Авторы новых снимков перечислены в `CREDITS.md`.
